# GSSpinner WebComponent
 
GSSpinner WebComponent is a wrapper around Bootstrap Spinner control
  
<br>
 
## Attributes
---
 
| Name               | Description                                              |
|--------------------|----------------------------------------------------------|
| color              | Bootstrap color (primary, secondary...)                  |
| small              | Render the smaller Bootstrap spinner                    |
| pulsar             | Boolean - true to pulse                                  |

<br>
 
## Example
---

**NOTE :** 
For more details, check [spinner.html](../../demos/spinner.html)
 

```HTML
<gs-spinner color="secondary" small></gs-spinner>
```

The spinner exposes a `status` role and defaults to the accessible label
“Loading...”; custom label text can be supplied in its default slot.
